
The folder contains six Jupyter notebooks, each corresponding to one of three datasets. 
For each dataset, there are two files: one for binary classification and one for multi-class classification.

Dataset 1: ToN-IoT
(URL: https://research.unsw.edu.au/projects/toniot-datasets)
ToN-IoT-Binary
ToN-IoT-Multiclass

Dataset 2: BoT-IoT
(URL: https://research.unsw.edu.au/projects/bot-iot-dataset)
BoT-IoT-Binary
BoT-IoT-Multiclass

Dataset 3: CSE-IDS2018
(URL: https://www.unb.ca/cic/datasets/ids-2018.html)
CSE-IDS2018-Binary
CSE-IDS2018-Multiclass
