# New-host incident-flow protocol

This protocol is declared before inspecting the larger samples' class supports or fitting models. It uses the predefined one-million-flow uniform samples and the frozen seed 42. It does not replace or repair the earlier fully host-disjoint protocol; that earlier protocol's empty and small test splits remain reported.

Every host observed anywhere in the original 100,000-flow development sample is treated as known and assigned to training. A host absent from that entire development sample is new. Each new host receives a stable hash assignment: below 0.6 training, 0.6-0.8 validation, and at least 0.8 test. A flow incident to a test host is a test target; a flow incident to a validation host is a validation target. Flows joining a validation host to a test host are excluded and counted. Other flows enter training. All original development rows must remain in training.

Test-assigned new hosts occur in neither training nor validation and have never appeared in the original development sample. However, known infrastructure and training-assigned hosts may be shared across the flow splits. Therefore the claim is new-host incident-flow classification, not an entirely host-disjoint network or an independent attack-episode evaluation. Full split snapshots include unlabeled context from the flows being classified; this is offline inference, not online arrival-by-arrival prediction.

Inspect and publish supports before fitting. Every binary class must be present in train, validation and test. Preserve failed datasets without drawing new seeds or silently dropping a class. If feasible, fit the same full edge-conditioned GNN, flow MLP and Random Forest at seeds 7, 19, 31, 43 and 59, with the already chosen learning rate 0.003, hidden width 16, two layers, dropout 0.2, weight decay 0.0001, at most ten epochs, patience three, and 100 trees (depth unrestricted on ToN, 16 on CSE/BoT). Only validation macro F1 selects epochs; no new hyperparameter or threshold search is allowed. Preprocessing is fitted on the new training split only. Report exclusions, shared infrastructure, class supports, all five seeds and every failure.

Larger samples contain the original development rows by design, but new test/validation targets have endpoints that were absent from those rows. This reduces direct identity overlap with the earlier development exercise; it does not prove attack-episode independence or rule out correlated infrastructure. Genuine event timestamps and causal labels are still unavailable.
